## Notes for contributors (delete before submitting)

**Status guidance:**
- ✅ Use only if a major AI provider has publicly committed to honoring it
- ⚠️ Use for files with real specs and adopters but no formal provider commitment
- 🚀 Use for new launches (under 12 months) with significant backing
- 🚧 Use for specs still in active drafting

**Prompt guidance:**
- Use `[BRACKETS]` for user inputs
- Don't hardcode specific products or brands
- Reference the official spec URL inside the prompt
- Specify format requirements clearly
- Test with at least one major AI tool before submitting

**Heads up guidance:**
- Be specific. "Doesn't always work" is weak. "Cloudflare's default settings block this; check your dashboard" is strong.
- Cite where possible. Link to the specific issue, spec, or analysis.
