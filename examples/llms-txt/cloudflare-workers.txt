# Why this is a notable example

Cloudflare's approach is structurally interesting:
- They split llms.txt by product (workers, ai, ai-gateway, agents, etc.) rather than 
  one massive file
- Every link points to the .md version of the doc page (the .md routes pattern)
- They include a top-level pointer to llms-full.txt for ingestion use cases
- The blockquote summary explicitly tells AI tools when to use llms.txt vs. llms-full.txt

For multi-product companies, this product-by-product split is more useful than 
one flat file — an AI agent only fetches the section relevant to what it's building.
