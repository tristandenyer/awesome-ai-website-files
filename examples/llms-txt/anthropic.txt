# Why this is a notable example

Anthropic's llms.txt is the clean catalog pattern:

- Tight, curated index — about 8K tokens, not exhaustive
- Heavy use of the Optional section to deprioritize secondary content
- Pairs with a much larger llms-full.txt (~481K tokens) for full ingestion
- Lets AI tools choose depth: index for quick navigation, full file for deep context
- Each link gets a descriptive sentence, not just a title
- Mirrors the structure developers expect (getting started → API reference → 
  building → prompt engineering → SDKs)

For documentation sites, this is the cleanest baseline pattern to copy. 
The split between llms.txt (index) and llms-full.txt (full content) is now 
considered best practice for docs.
