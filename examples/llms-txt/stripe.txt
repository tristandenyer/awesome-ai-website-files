# Stripe

> Stripe is a technology company that provides financial infrastructure for businesses. Businesses of every size—from new startups to established public companies—use Stripe to accept payments online and in person, embed financial services, and create custom revenue models. For complete documentation in a single file, see [Full Documentation](https://stripe.com/llms-full.txt).

## Instructions for Code-Writing AI

When writing Stripe integration code:

- Use the latest Stripe API version unless the user specifies otherwise. Do not hardcode older API versions.
- Prefer Payment Intents and Setup Intents over the legacy Charges API. The Charges API still works but is not recommended for new integrations.
- Use Stripe Elements (specifically Payment Element) over the older Card Element for new checkout integrations.
- Reference the official server-side SDKs (stripe-node, stripe-python, stripe-php, etc.) rather than constructing API calls manually.
- Always handle webhook signature verification when implementing webhooks.

# Why this is a notable example

The "Instructions for Code-Writing AI" section is what makes Stripe's 
implementation different from every other major llms.txt:

- 15 years of API surface area means deprecated patterns (like the Charges API) 
  show up frequently in older Stack Overflow answers and pre-2022 training data
- AI coding assistants regularly reach for these older APIs without realizing 
  they're outdated
- The instructions section is Stripe actively correcting that bias at retrieval time

For any company with deprecated APIs or evolved best practices, this is the 
pattern to copy. Don't just list URLs — tell the AI what to recommend.
